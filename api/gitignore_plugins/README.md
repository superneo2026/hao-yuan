# gitignore_plugins（本地私有插件目录）

这个目录用于存放**不希望进入 git 仓库**的豪源插件。

- 把插件目录放到这里，例如 `gitignore_plugins/<plugin-name>/`，其中包含 `plugin.json`、`plugin.py`（可选 `routes.py` 等）。
- 这里放置的插件会和 `api/plugins/` 中的插件一样被自动发现、加载，正常出现在「插件」页面，可启用、停用或删除。
- 本目录下的内容默认都被 `.gitignore` 忽略（仅保留本说明文件），因此放在这里的插件不会随仓库提交或分发。
- 适合放置个人、私有、含敏感逻辑或密钥的插件；需要公开分发的插件请放在 `api/plugins/`。

提示：手动放入插件后重启一次后端即可被发现；之后在插件页启用即可生效。
