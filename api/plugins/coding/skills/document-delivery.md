## Audience first
Identify who reads the deliverable. A resume/CV or cover letter is sent to an interviewer: it must read as a finished professional document, not a working notebook.

## No internal meta content
Never add sections the user did not ask for. In particular, do not include interview Q&A, "高频追问与回答要点", JD-matching walkthroughs, "岗位匹配" checklists, preparation notes or talking points in an outward-facing document unless the user explicitly requests them.

## Reference fidelity
When a template or reference file is supplied, reproduce its structure and style exactly and change only the requested content. When the target file already exists, edit it in place: keep the markup, CSS, section order, numbering scheme and naming unchanged except for the requested diff.

## Verify before delivery
Open the result and confirm: (1) the requested content is present and correctly numbered, (2) no unrequested section was introduced, (3) the visual style matches the reference, and (4) export links and filenames are still valid.
