# 用户账号管理（user-account）

为豪源站点添加一层本地账号密码保护，适合在个人电脑、局域网或公网部署时保护隐私内容。

## 功能

- 插件启用后，首次使用需要设置用户名和密码
- 设置完成后，所有前端页面与 `/api` 接口都需要登录
- 登录后可在侧栏账号入口修改用户名和密码
- 使用本地 PBKDF2-SHA256 加盐哈希保存密码，密码不以明文落盘
- 登录态使用 HMAC 签名的 HttpOnly Cookie，默认 7 天有效
- 连续登录失败 5 次会锁定 5 分钟；锁定到期后重新计数，再次连续失败 5 次会再次锁定 5 分钟
- 登录成功后会清零失败次数

## 使用

1. 在豪源前端「插件」页启用「用户账号管理」
2. 首次启用会弹出账号设置，设置用户名与密码
3. 之后访问豪源任意页面会先进入登录页
4. 登录后在左下角账号入口可以修改用户名或密码

## 数据与重置

账号数据保存在：

```
api/data/user_account.json
```

如果忘记密码，停止后端后删除该文件（或把 `configured` 改为 `false`），重启后即可重新设置账号。

## 开发说明

- `plugin.py` 同时包含账号存储、鉴权中间件和 6 个 API 路由
- 通过 `ctx.add_middleware(...)` 注册全局访问门禁
- 通过 `ctx.on("plugin.toggled", ...)` 实现启用/停用的即时生效
