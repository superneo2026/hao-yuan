# 远程管理（remote-management）

官方插件。让一台豪源（云端 / 办公电脑）通过浏览器直接管理另一台豪源（家里电脑 / 工作站），两端都只需安装并启用本插件。

## 能力

- **生成连接密钥**：被管理方生成密钥，密钥中自带被管理方的访问地址，可直接复制发给管理方。
- **接受管理**：收到管理请求后必须手动批准；可立即取消、拒绝、恢复或删除授权。
- **进行管理**：输入对方的连接密钥即可发送管理请求；对方批准后，在侧栏「远程管理」下出现该系统的二级菜单。
- **嵌入式豪源**：右侧直接加载对方的豪源界面，可以正常发任务、看会话、改文件；支持放大为独立全屏，退出放大后回到嵌入式布局。
- **多系统切换**：侧栏会列出所有已纳入管理的系统，点击二级菜单即可切换。
- **可拆卸**：关闭或卸载插件不会影响豪源本体；插件状态保存在 `api/data/remote_management.json`。

## 使用流程

1. 两台豪源都安装并启用「远程管理」插件，然后重启后端。
2. 被管理方打开「远程管理」→「生成密钥」，复制完整连接密钥。
3. 管理方打开「远程管理」→「进行管理」，粘贴连接密钥并发送请求。
4. 被管理方在「接受管理」中批准请求。
5. 管理方点击「刷新授权」，侧栏出现被管理系统，点击即可进入。

## 部署要求

- 被管理方必须能被管理方访问。内网电脑建议使用 Cloudflare Tunnel、Tailscale Funnel、frp 等公网隧道，或在路由器上做端口映射。
- 如果管理方是 HTTPS 页面，被管理方的地址也必须是 HTTPS，否则浏览器会拦截混合内容 iframe。
- 如果地址不是反向代理自动识别的公网地址，请在「远程管理」顶部填写「公网访问地址」，再生成连接密钥。
- 被管理方启用了「用户账号管理」时，本插件会自动签发兼容的临时会话，管理方无需再次输入被管理方的账号密码。

## 数据与安全

- 管理请求必须经被管理方批准后才会签发远程会话令牌；令牌只能访问对应的已批准请求，取消/删除授权或删除密钥后立即失效。
- 连接密钥等同于邀请码，请只发给信任的人；泄露后可在插件页删除密钥，相关授权会一并取消。
- 本插件只负责在两端之间建立授权关系。请确保豪源服务本身通过 HTTPS 暴露，并妥善保管连接密钥。

## 卸载

在「插件」页关闭并卸载「远程管理」即可。建议先在「接受管理」里取消已批准的授权，再卸载插件，避免对方保留仍然可用的会话。删除 `api/data/remote_management.json` 可彻底清空本机远程管理数据。
